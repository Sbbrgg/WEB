Дескрипторы

Дексрипторы физического форматирования

<p> (Paragraph) – этот дескриптор описывает абзац;
<b> (Bold) – делает шрифт жирным;
<i> (Italic) ‒ делает шрифт курсивным;
<u> (Underline) ‒ делает шрифт подчёркнутым;
<u> (Teletype text) ‒ делает шрифт моноширным (занимает одинаковую площадь на экране);
<sup> (Superscript) ‒ Верхний индекс;
<sub> (Subscript) ‒ Нижний индекс;
<pre> (Preformatted) ‒ 
Этот декспритор создаёт предформатированный текст, 
в котором сохраняются отступы и 
переносы строк.
Кроме того, предформатированный текст всегда отображается моноширным шрифтом;

Дескрипторы логического форматирования

Для наиболее эффективного анализа нашей страницы поисковыми машинами вместо дескрипторов физического форматирования рекомендуют использовать дескрипторы логического форматирования. К ним относятся:
<strong> (Bold) ‒ делает шрифт жирным
<em> (Emphasis) ‒ делает шрифт курсивным
<code> (Emphasis) ‒ делает шрифт моноширным
<abbr> (Abbreviation) ‒ этим декспритором желаттельно выделять аббревиатуры
<cite> (Citation) ‒ этим декспритором желаттельно выделять цитаты

CSS - Cascade Style Sheet

Предназначены для оформления внешнего вида страницы В то время, как HTML разметка создаёт структуру страницы и наполняет её содержимым CSS стили оформляют эту структуру и придают ей внешний вид. СSS стили можно применять непосредственно к отдельным дискрипторам при помощи атрибута 'style', такие стили называют локальными. Но вся мощь CSS заключаются в том, что стили могут применяться хоть к тысяче страниц, для этого их выносят в отдельный файл. Хотя, если сайт представляет собой одну страницу, то стили можно описать в заголовке.
