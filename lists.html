Списки

Список определений

Позволяет создавать списки терминов с их разъяснением

<dl> Definitions List;
<dt> Description termin;
<dd> Description Details;
<dt> и <dd> всегда используются парой;
Нумерованный список
Позволяет нумеровать элементы текста. Это нужно для перечисления в строгом порядке.
Маркированный список
Позволяет перечислять элементы текстов в любом порядке
Список определений
Позволяет перечислять понятия и давать им определения

Нумерованный список

<ol> Order List;
<li> List Item;
  1. List Item 1
  2. List Item 2
  3. List Item 3
  4. List Item 4
  5. List Item 5

При необходимости список можно прервать и продолжить позже

  2. Продолжение первого списка
  3. Продолжение первого списка
  4. Продолжение первого списка
  5. Продолжение первого списка

Маркированный список

<ul> Unordered List;
<li> List Item;
  • Item 1
